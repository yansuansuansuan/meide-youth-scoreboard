3. 怎么让网站更新？

  1. 在上面录入本次活动的积分，确认无误后点“下载 ledger.json”。
  2. 点击“打开 GitHub 数据文件”，在 GitHub 里选择编辑/上传替换。
  3. 把下载的新文件覆盖 data/ledger.json，提交保存。
  4. GitHub Pages 更新后，总榜、活动榜、成长档案会自动重新计算。
为什么先这样？

纯 GitHub Pages 没有安全的服务器端登录。把 GitHub 写入令牌直接塞进网页会暴露，所以第一版宁愿多一步上传，也不把“管理员密码”做成假的安全机制。
